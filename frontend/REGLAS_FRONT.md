**Dónde trabaja normalmente:** `frontend/`.

1. Crear una rama por tarea, por ejemplo `frontend/pantalla-registro`.
2. Hacer los cambios de pantallas y formularios en esa rama.
3. Subirla a GitHub y abrir un PR hacia `main` con una explicación corta.
4. Pedir a otro integrante de Frontend que revise cuando corresponda.
5. Si cambian los datos que intercambian con la API, avisar a Backend antes de integrar.
