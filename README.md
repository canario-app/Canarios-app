# Canarios-app

**Estado del proyecto:** etapa inicial de organización y definición de requisitos. Las funciones descritas son objetivos del proyecto; **todavía no están implementadas**.

## ¿De qué trata?

El proyecto busca desarrollar una aplicación para **organizar y consultar la información de un criadero de canarios** en un solo lugar. Permitirá llevar un registro de cada ave, su historial y sus relaciones de reproducción, de forma que la información sea más fácil de mantener y consultar.

## ¿Qué hará la aplicación?

- **Registro de canarios:** mantener fichas con identificación por anilla, color, nacimiento, generación, disponibilidad y otros datos acordados.
- **Historial de cada ave:** consultar sus progenitores, crías y títulos obtenidos en concursos.
- **Gestión de parejas y cruces:** registrar parejas, fechas de apareamiento y crías asociadas.
- **Seguimiento del criadero:** guardar observaciones de los canarios y horarios de alimentación.
- **Consulta de información:** encontrar y revisar los registros sin depender de apuntes dispersos.

## Funciones propuestas para una etapa posterior

Se contempla estudiar la incorporación de:

- **Sugerencias de parejas** según criterios que se definan con el cliente.
- **Simulación de posibles resultados de cruces**, sujeta a datos y reglas genéticas validadas.
- **Monitoreo mediante sonidos**, cuyo objetivo y alcance todavía deben definirse.
