**Dónde trabaja normalmente:** `database/`, incluidas de ejemplo `migrations/` y `seeds/`. (pueden cambiar segun ustedes modifiquen la estructura, esos son de ejemplos)

1. Crear una rama por tarea, por ejemplo `bd/crear-tabla-canarios`.
2. Guardar los cambios de tablas, migraciones o datos de prueba en esa rama.
3. Subirla a GitHub y abrir un PR hacia `main`.
4. Revisar el cambio entre los integrantes de BD cuando corresponda.
5. Avisar a Backend si se agregan, eliminan o renombran tablas y campos que utiliza.
